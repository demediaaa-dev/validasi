Panduan Deploy ke GitHub & Vercel

Aplikasi ini dirancang dalam arsitektur Single-File Web App (Zero-Build) sehingga sangat cepat dan gratis di-hosting melalui GitHub + Vercel:

Langkah 1: Simpan Kode sebagai index.html

Simpan seluruh kode aplikasi ini ke dalam satu file bernama index.html di folder proyek Anda.

Langkah 2: Upload ke Repository GitHub

Buat repository baru di github.com (misal: rekap-aslinmas-musirawas), lalu upload file index.html tersebut (atau push via Git).

Langkah 3: Import & Deploy di Vercel

Buka vercel.com → Login dengan GitHub → Klik "Add New Project" → Pilih repo rekap-aslinmas-musirawas → Klik "Deploy" (Framework Preset biarkan Other). Dalam 15 detik website langsung online!
